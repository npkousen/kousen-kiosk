Privacy Policy

Kousen Kiosk keeps appliance setup data on your own device.

This policy applies to Kousen Kiosk, the open-source appliance setup project and public documentation site available at kousenkiosk.com.

Last updated: August 16, 2026

1. Information The Project Handles

Kousen Kiosk may handle local appliance setup details such as the kiosk URL, display output, display mode, browser window size, audio sink selection, WiFi configuration, and local browser profile data created while using Chromium on the kiosk device.

2. Local Device Storage

The installer writes configuration files and logs on the kiosk device. These can include the kiosk URL, display settings, browser startup logs, audio selection logs, and home-key activity logs. These files are stored locally on the device unless you choose to copy, back up, or share them.

Chromium may also store normal browser profile data on the kiosk device, such as cache, local storage, cookies, permissions, and other site data created by websites the kiosk opens.

3. WiFi and Network Configuration

If you use the WiFi helper, NetworkManager stores the selected network connection on the Linux device. WiFi passwords and other connection details are managed by the operating system, not by kousenkiosk.com. Do not commit WiFi passwords, SSH keys, tokens, or private network notes to the public repository.

4. No Kousen Kiosk Accounts or Backend

Kousen Kiosk does not require user accounts and does not include its own hosted backend database for collecting appliance setup information. The public documentation site does not receive, store, or manage your local kiosk configuration through the project itself.

5. CommandCenter and App Links

The default kiosk URL opens Kousen CommandCenter at kousen.cc. CommandCenter and any app cards, media services, LAN tools, or third-party sites opened from the kiosk may handle data according to their own privacy policies and browser behavior.

6. Hosting and Technical Logs

When kousenkiosk.com is hosted publicly, the hosting provider may process standard technical request data needed to deliver the site, such as IP address, browser details, timestamps, requested paths, and basic server or CDN logs.

7. Cookies, Analytics, and Tracking

Kousen Kiosk does not intentionally include advertising trackers, analytics dashboards, or behavioral profiling tools. Essential browser and hosting mechanisms may still be used to load static files securely and reliably.

8. Data Security

Because kiosk setup data and browser data are generally stored on your own device, protecting access to the device, Linux admin account, SSH access, and Chromium browser profile is important. Avoid storing sensitive secrets in kiosk URLs, local notes, browser pages, or public repository files.

9. Children's Privacy

Kousen Kiosk is not directed to children under 13, and kousenkiosk.com does not knowingly collect personal information from children through Kousen Kiosk's local-first setup tools.

10. Changes to This Policy

This Privacy Policy may be updated from time to time. The revised version will be posted on this page with a new "Last updated" date.
